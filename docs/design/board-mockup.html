Design notes

Tokens

Every colour comes from the SPA's existing @theme block — accent #1299A7, ink #2F3448, ground #FAFAFA, radii 6/10/12. The dark palette is new; the project has no dark tokens yet.

Vote placement

The vote sits first in the reading order on the list, because voting is the page's primary action. On roadmap cards it moves right, where the narrow column makes the title the thing worth leading with.

Status encoding

Status reads twice — a coloured chip in the list, a coloured top rule on each roadmap column. Colour is never the only signal; the label is always present.

Identity

Where features.vote shows "Anonymous session", this shows the verified shop domain. That chip is the visible proof of the HMAC handshake, and the reason one-vote-per-store holds.

Changelog loop

Completed requests carry a "Shipped in 3.2" link back to the What's New entry — the feature_id link from the plan, made visible.

Embedding

Fluid to 320px with no horizontal body scroll; only the roadmap scrolls sideways, inside its own container. The 56px bar is sticky so tabs stay reachable inside a short iframe.
